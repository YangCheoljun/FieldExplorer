# 현장탐방 기록 앱

이 프로젝트는 제주 여행, 농업 교육, 역사 탐방처럼 직접 현장을 다니며 보고 들은 내용을 기록하기 위한 앱입니다.

사진, 음성메모, 위치, 설명을 한곳에 모아두면 나중에 탐방 기록을 다시 찾아보고, 정리하고, 공유하기 쉬워집니다.

## 이 앱이 필요한 이유

현장 탐방을 하다 보면 여러 정보가 흩어지기 쉽습니다.

- 사진은 휴대폰 사진첩에 저장됩니다.
- 메모는 종이나 메모 앱에 따로 적습니다.
- 위치는 기억에 의존하는 경우가 많습니다.
- 음성 설명이나 강의 내용은 따로 녹음됩니다.

이 앱은 이런 기록을 하나의 탐방 단위로 묶어 관리하는 것을 목표로 합니다.

## 주요 사용자

- 제주 여행을 기록하고 싶은 사람
- 농업 교육 현장에서 작물, 시설, 강의 내용을 정리하고 싶은 사람
- 역사 탐방 중 장소별 사진과 설명을 남기고 싶은 사람
- 현장 조사, 답사, 견학 내용을 나중에 보고서로 정리하고 싶은 사람

## 핵심 기능

- 탐방 기록 만들기
- 장소별 사진 저장
- 음성메모 녹음 또는 첨부
- 현재 위치 저장
- 장소 설명 작성
- 날짜별, 주제별 기록 확인
- 지도에서 탐방 위치 보기

## 현재 단계

현재는 아주 작은 MVP 웹앱이 추가된 단계입니다.

설계 문서:

- `README.md`: 프로젝트 소개
- `기능기획서.md`: 필요한 기능 정리
- `화면구성.md`: 앱 화면 구성 계획
- `데이터구조.md`: 앱이 저장해야 할 정보 구조

실행 파일:

- `index.html`: 앱 화면
- `style.css`: 화면 디자인
- `app.js`: 기록 저장과 목록 표시 기능

## 실행 방법

가장 쉬운 방법은 `index.html` 파일을 브라우저로 여는 것입니다.

조금 더 안정적으로 실행하려면 이 폴더에서 아래 명령어를 실행한 뒤 브라우저에서 `http://localhost:4173`을 엽니다.

```bash
python3 -m http.server 4173
```

## MVP에 포함된 기능

- 기록 추가
- 제목 입력
- 지원되는 브라우저에서 제목 음성 입력
- 사진 여러 장 첨부와 미리보기
- 음성메모 파일명 저장
- 지원되는 브라우저에서 바로 음성녹음
- 위치 메모
- 지원되는 브라우저에서 현재 위치 가져오기
- 설명 메모
- 태그 입력
- 기록 목록 보기
- 새로고침 후에도 브라우저에 기록 유지

## 휴대폰 테스트 참고

휴대폰에서 사진 촬영, 마이크 녹음, 현재 위치 기능을 테스트하려면 휴대폰과 컴퓨터가 같은 Wi-Fi에 있어야 합니다.

컴퓨터의 로컬 주소 예시:

```text
http://192.168.68.101:4173
```

브라우저와 보안 설정에 따라 마이크, 위치, 음성 인식은 권한 허용이 필요하거나 일부 동작하지 않을 수 있습니다. 특히 휴대폰에서는 HTTPS가 아닐 때 일부 기능이 제한될 수 있습니다.

아이폰에서 제목 음성 입력 버튼이 잘 동작하지 않으면 제목 입력칸을 누른 뒤, 아이폰 키보드의 마이크 버튼으로 받아쓰기를 사용합니다.
